# OpenClaw Calendar

Aplicación de uso personal para gestionar Google Calendar
mediante un asistente privado OpenClaw.

Permite consultar, crear, modificar y eliminar eventos,
según las instrucciones del propietario y los permisos autorizados.

No ofrece registro ni servicios al público.

Esta integración es independiente del sistema de copias
de seguridad del propietario.
